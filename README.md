# Proyecto para el tercer control del CDC de la asignatura IS

## Objetivo
Gestionar un almacen
## Breve descripción
Se dispone de una serie de funcionalidades asociadas a él:
- Añadir productos al almacen (individualmente o en grupo).
- Eliminar productos (invividualmente o en grupo).
- Devolver el listado de productos que actualmente dispone el almacen en stock.
- ...
  
La solución seguirá el patrón MVC. Por ello, se han creado 3 paquetes para organizar el código en función de este patrón.

Se dispone de una clase GestorTest encargada de realizar algunas pruebas unitarias a la clase Gerente.

El proyecto tiene naturaleza Gradle
